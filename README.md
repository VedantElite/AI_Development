




# Telegram Data Cleaning Bot____________
A Telegram-based data cleaning bot that helps you process and clean datasets through simple chat commands.  
The bot runs locally on your machine to ensure complete privacy—your data never leaves your system.

# 🚀 Features
- Clean and preprocess datasets via Telegram chat
- Remove duplicates, missing values, and unnecessary formatting
- Quick data transformation without coding
- Fully local execution for privacy protection

# 🔒 Privacy
This bot is designed to run locally, meaning all data processing happens on your device.  
No data is stored or sent to external servers.
